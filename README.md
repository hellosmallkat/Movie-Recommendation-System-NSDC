# Overview

This repository contains my implementation of the **National Student Data Corps (NSDC) Movie Recommendation System Project**.

Recommendation systems play a critical role in modern digital platforms by helping users discover content tailored to their interests. In this project, I developed a movie recommendation system using the **MovieLens** dataset, exploring collaborative filtering techniques and matrix factorization to predict user ratings and generate personalized recommendations.

Working through the complete machine learning workflow, I explored data preprocessing, exploratory data analysis, recommendation algorithms, model training, and evaluation. The project strengthened my understanding of recommender systems and demonstrated how machine learning can personalize user experiences across entertainment, e-commerce, and online services.

Preparing recommendation data is essential for producing accurate predictions.

During preprocessing, I gained experience with:

* Cleaning movie rating datasets
* Organizing user-item interactions

* Splitting datasets into training and testing sets
* Formatting data for recommendation algorithms

These preprocessing techniques improved the quality and consistency of model inputs.

## Recommendation Systems

The primary objective of this project was developing a personalized recommendation engine.

I gained experience with:

* Collaborative filtering

## Matrix Factorization (SVD)

A major focus of this project was learning **Singular Value Decomposition (SVD)** for collaborative filtering.

During this stage, I explored:

* Matrix factorization
* Latent feature extraction
* User preference modeling
* Dimensionality reduction
* Rating prediction

SVD learns hidden relationships between users and movies, allowing recommendations even when users have not rated every film.
